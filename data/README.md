# Example datasets (downloaded unmodified; none is redistributed under any licence of ours)

| file | what | source |
|---|---|---|
| CreditCard.csv | AER credit-card applications, 1,319 rows | github.com/vincentarelbundock/Rdatasets, `csv/AER/CreditCard.csv` (R package AER; Greene) |
| titanic_seaborn.csv | Titanic, 891 rows; contains `alive`, a literal copy of the target | github.com/mwaskom/seaborn-data `titanic.csv` |
| pd_speech.csv | Parkinson's speech features, 252 rows x 750 features, one row per subject (no subject id) | github.com/vincentarelbundock/Rdatasets, `csv/modeldata/pd_speech.csv` (original: Sakar et al. 2019, UCI) |
| stocks.csv | monthly closing prices of 5 stocks, 2000-2010 | github.com/vega/vega-datasets `data/stocks.csv` |
| Orthodont.csv | orthodontic growth, 108 rows = 27 subjects x 4 visits (entity-leakage test) | Rdatasets `csv/nlme/Orthodont.csv` (R package nlme) |
| ChickWeight.csv | chick weights over time, 578 rows = 50 chicks (entity-leakage test) | Rdatasets `csv/datasets/ChickWeight.csv` (R `datasets`) |
| VerbAgg.csv | verbal-aggression questionnaire, 7,584 rows = 316 people x 24 items (entity-leakage test) | Rdatasets `csv/lme4/VerbAgg.csv` (R package lme4) |
